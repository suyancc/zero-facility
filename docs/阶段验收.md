## 实际构建体积

- WASM：39,514,754 bytes。
- PCK：46,700 bytes。
- JS：279,815 bytes。
- 其他页面、图标与音频支持文件为少量附加资源。
- 当前标准 Python 本机服务器未启用 gzip/Brotli，浏览器资源记录显示主要传输约39.9 MB。
- **暂未达到文档中约30 MB的初始传输预算。**线上发布前应验证 gzip/Brotli 与加载体验；不能把模板ZIP大小当作游戏实际下载大小。

## 过程中修复／处理

1. headless 测试中合成音产生退出时音频对象残留：无音频设备测试模式不启动声音，正常退出显式停止播放器。
2. 原工程直接导出会把 MCP 自动加载与编辑器环境带入，并出现资源退出警告；改为 `tools/build-web.ps1` 隔离导出，复建无该错误。
3. 首轮按场景选择导出漏掉脚本预加载的关卡依赖；隔离构建改为完整资源导出，确认 level_01 与全部游戏脚本被打包。
4. 两次直接命令启动的模板下载任务无进展，均已停止；使用经验证的 PowerShell→Python stdin 方式完成下载。
5. 根据实际截图降低过亮灯光并打开4×MSAA，缓解细线锯齿。

## 如何继续运行

- Godot中按F5，主场景已设置。
- Web构建：PowerShell运行 `./tools/build-web.ps1`。
- 本机Web服务：`./tools/serve-web.ps1`，地址 http://127.0.0.1:8765/。
- 本轮已启动的临时MCP预览服务最长运行1小时；如果端口失效，可运行上述脚本重启。
- 不要同时启动两个占用8765端口的服务。
