# 0.4 策略潜行：巡检有记忆，玩家有反制

## 核心循环
观察巡检 → 决定轻运还是冲刺 → 获取通行扫描 → 必要时完成跨区中转 → 摆脱追捕 → 在接收台停稳。
失败从“看到即死”改为：视野内持续确认后追捕，贴近捕获才失败。障碍挡住视线后，巡检只知道最后看到的位置，不追踪不可见玩家的实时坐标。

## 机器人
五状态：巡逻、调查、追捕、搜索、返回。多点路线由共享网格 BFS 绕柜导航，绝不直线穿柜追人。听觉来自猛烈碰撞、快速滚动和诱饵；听觉只获得声源位置。持续视觉确认约 0.65 秒。失去视线后到最后位置搜索，再回巡逻。确认后可呼叫一台空闲同伴调查最后位置，有无线电冷却。

## 玩家反制
- 默认重力参数不变；按住 Shift 轻运，限速 2，减少快速滚动噪声。
- 鼠标指向地面，E 或右键投掷声响诱饵，最多 5 米、每关 2 枚，完成站点补充 1 枚（最多 2）。诱饵持续数秒，吸引可听到的非直接追捕巡检。
- 利用货柜断开视线；接收台在有人追捕时不签收，必须先摆脱。
- Tab 按住全场俯瞰；平时镜头轻跟随，避免扩大地图后角色变得太小。

## 地图 / 目标
17×13 格，相比 11×9 约增加 123% 格子数量。西区扫描站和东区中转站构成多个分区；每关至少先取得扫描标记，跨区中转关还需第二站。站点短暂停稳完成，UI 与地面标记显示当前目标。关卡仍确定性生成、重试相同布局、难度有上限。只验证通路连通，不再声称有巡检永远到不了的安全外围。

## 控制范围
不加入武器、复杂物品栏或联网排行榜。延续程序角色和现有场景资源，将开发时间投入行为可读性、追逐反馈与关卡策略。
