# 0.6.9 工业科幻视觉第一轮

## 交付范围

本轮把用户参考图中的灰白工作服、橙色工具挂带、蓝色终端、分区编号、设施墙板和管线转化为可玩的网页版本。采用原创低多边形／程序几何，不是写实人物重建，也没有把参考图作为宣传渲染冒充游戏画面。

这是一轮可运行的视觉基底升级，未完成参考图中的所有资产。四区独立大型机组、完整写实角色、全部装备重制和全新的结算动画仍属后续范围。

## 界面

- 准备界面改为暗色工业终端：品牌区、任务简报、四张模型装备卡、两格背包、实际维修员模型展示、右侧装备 3D 预览。
- 人物展示直接实例化游戏使用的维修员场景，不使用概念图替代；准备时仅渲染一次，游玩时关闭 SubViewport 更新。
- 游玩 HUD 使用独立任务底板、顶栏操作区和体力底板；准备时隐藏游玩任务／体力，避免与准备面板重叠。
- 统一冷蓝灰、橙色交互、红色危险的色彩角色；面板改为小倒角细边框，去掉大范围阴影。
- 暂停、设置、失败和成功沿用新的主题；保留原有按钮、快捷键和保存行为。设置窗口层级高于背包，避免准备时背包遮挡滑块。
- 装备格状态没有变化时不再无条件 queue_redraw；保留选中、数量、快捷键、选择反馈和冷却显示。

## 人物与巡检

- 维修员：灰白工作服、深色护具、橙色挂带、胸前终端、工具袋／工具、背包固定带、手套和安全靴。
- 用简化脸部与头发替换整块发光面罩，收窄上身，调整腿部比例。保留分段手脚、骨架节点名称与原有走／跑／潜行／搬运驱动；同步更新脚底贴地计算。
- 巡检：增加传感器框、外壳护甲、橙色警示带和固定件。原有视野、确认、追捕、失联、干扰行为不变。
- 巡检的刚性外壳按材质合并网格。不会将人物关节、门或可交互物品合并为静态模型。

## 设施

- 四个现有分区加上金属地板分缝、不同的暗色地坪和地面区域编号。
- 分区墙增加墙板、底部标线、固定件和顶盖；背景增加外露服务管线与灯具外壳。
- 箱体材质改为更中性的工业灰，保留原有轮廓与位置。
- 新装饰全部放在无碰撞的独立节点中，按共享材质合并。没有添加新的动态灯、阴影灯或后期特效。
- 地图导航、门禁碰撞、任务位置、机关参数不变。装饰不会产生看不见的障碍。

## 验证

- 原生 203 项检查通过，包括准备界面层级、两槽／四卡、人物展示开关、刚性网格批次和装饰无碰撞等新增检查。
- 独立浏览器在 1280×800、1600×900、1024×768 检查准备、四件装备选择、第二槽、开始、暂停、重试，以及准备时打开／关闭设置。
- 同机以旧 0.6.8 Web 导出为对照，采集音乐开启、第一关静止位置的预热后帧间隔；数字以随附实测 JSON 为准。测试不代表激烈追捕、高 DPI 或所有设备的性能承诺。
- 重跑实际 WebAudio 检查，保留 0.6.8 重复恢复播放修复。没有为此次视觉更新改动音频混音逻辑。
- 退出资源警告仍沿用已有已知问题，不宣称全部资源泄漏已修复。

### 性能抽样边界

同机两轮短测并不完全一致：早一轮帧间隔中位数 25.0→25.0 ms、P95 33.3→33.4 ms；最终三尺寸检查这一轮为 16.8→24.8 ms、P95 25.3→25.1 ms（旧版→新版），样本数 295→292。不能据此声称没有任何性能代价或所有电脑都不卡；这里只确认已测流程没有脚本异常，尾部帧间隔相近，中位数仍有波动。

另用真实浏览器调整窗口至 1400×900 再恢复 1280×800，并检查人物区域像素，确认人物预览没有因一次性渲染而在缩放后消失。
