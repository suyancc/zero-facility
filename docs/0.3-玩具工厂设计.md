# 0.3 玩具工厂 · 从网页展示转向游戏体验

## 目标
保留重力参数和刚体碰撞尺寸，不改变已认可的手感。取消贯穿屏幕的网页式顶栏、底栏和白色侧卡，改为角落悬浮信息与底部短结算。相机不再为侧边卡片平移，货场始终居中。

## 场景与角色
- 正交相机放大，玩具工厂浅蓝、奶油、杏橙配色。
- 切面厂房、后方窗户、动态传送带、纸箱堆、厂房地面，取代纯黑背景。
- 巡检机器人：圆角头壳、双眼、天线灯、轮组、行走轻摆；视线与朝向继续一致。
- 玩家包裹：圆角纸箱、封箱胶、标签、脸部和脸颊；速度倾斜和碰撞挤压仅作用于视觉，不改变物理碰撞体。

## 轮换委托
1. 标准件：躲避巡检并送达。
2. 易碎件：前三次猛烈碰撞可继续，第四次失败；强度低于 1.1 的轻碰不扣保护。
3. 中转件：先到黄色扫描环，再到终点。扫描环位于已验证安全路线上的 (0,2) 格。
重复此顺序，保持原程序布局与难度封顶。每关一枚完成奖章，目标时间内完成与不超过一次碰撞各加一枚。奖章为本次结算反馈，尚无历史奖章存储。

## 声音
新增 20 秒原创合成音乐循环（钟琴式音色、低音、轻打击）与 20 秒机器室环境循环；不是网络音乐，不含人声。源代码 tools/compose_audio.py 可重现，需要 numpy/scipy/soundfile。首个开始操作后播放，受总音量与静音控制；暂停和失败时压低音乐，靠近管理员降低音乐，胜利稍抬高。保留 Kenney 碰撞和 UI 音效。已有素材许可不变。

## 验收重点
旧版物理与视野测试回归；新增三种任务、碰撞阈值、扫描门控、重试清理、音乐资源循环测试。浏览器实际输入验证关卡流程，检查中文字体和 UI 缺字，截图检视可读性。音频数值和播放状态可以验证，但不能替代人在扬声器上的听感验收。
