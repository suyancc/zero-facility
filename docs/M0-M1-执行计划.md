- 首轮 UI 暂用英文保证无外部字体依赖；正式中文 UI 等 M2 引入可分发字体。
- 声音为代码生成的短提示音，无第三方音频素材。
- 第一关可以单独在编辑器打开检查环境；运行请使用主场景。
- 不制作第二、第三关，直到第一关手感和视觉切片通过。
