# 0.3 玩具工厂 · 验收记录

## 已实现
- 删除横贯屏幕的网页式上下栏和白色侧卡；角落 HUD、底部短结算、稳定居中放大相机。
- 工厂墙面 / 窗 / 地面 / 堆货区 / 动态传送带；奶油与浅蓝玩具配色。
- 程序圆角巡检机器人、双眼、天线、轮组、轻摆；圆角纸箱脸、标签、胶带、运动倾斜和碰撞挤压。
- 关卡轮换标准件、易碎件、扫描中转件；猛烈碰撞四次损坏，扫描前禁止签收；完成、速度、低碰撞三枚奖章条件。
- 原创 20 秒音乐与机器环境声，循环播放，首个开始操作解锁，静音、总音量、暂停压低与警戒混音。

## 已执行测试
- `tests/run_tests.gd`：42 项检查、0 失败。最终独立测试和 OpenGL 截图进程无错误输出。
- `tests/v2_route.gd`：Godot headless 固定步长、Input.action_press 驱动，第 1、2、3、24、100 关均在 15.0333 游戏秒完成。未传送包裹、未强制胜利；均走构造安全路线。
- 浏览器真实页面：0.3 从旧存档第 4 关启动，进入游戏；音乐与环境播放状态为 true。
- 独立浏览器上下文音频探测：正常混音 RMS 约 0.0433，静音后 0；暂停时音乐由约 -18.75 dB 降至 -28.33 dB。探测器仅用于测试，未写入游戏 HTML。
- V3 浏览器方向键路线脚本有两段实际输入记录，但未完成通关；旧数字方向控制器偏航撞到货柜，后续隔离浏览器会话关闭，未把它计为通过。五关通关证据来自上述 Godot 输入回归，不混用旧版网页通关结果。
- 已复核网页游戏画面及原生扫描任务 / 失败 UI 截图。失败 UI 截图由专用测试设置结果状态，仅为展示布局，不冒充实玩检测证据。

## 限制
- 尚未由人听音验收、未做手机 / 全浏览器 / 低配与长时间压力测试；并行网页实例会影响帧率，不承诺固定帧率。
- 连续关卡并非永不重复，难度有上限；新任务每三关轮换，扫描环位于外围安全路线上。
- 奖章暂不保存最佳记录；包裹挤压和角色动作均为程序动画，不是骨骼动画。
- 最初对带 MCP 插件的编辑器执行导入时曾出现退出资源残留警告；最终独立测试和隔离 Web 导出无同类报错。插件原样保留。
- 本轮备份：`exports/backups/0.2-before-toy`，源码与项目设置已备份，原有第三方资源未改动。
