# 0.2.0 夜班潜行：实现与验收

日期：2026-10-03。对应用户要求：全中文与视听升级、连续生成关卡、具有有限视野且自主移动的管理员。

## 已实现

### 界面与表现
- 标题、任务卡、状态栏、投递结果、下一关、暂停、设置、音量和提示全部中文；按键标识、素材作者名和许可简称保留原名。
- Noto Sans SC派生静态字体，500字重，按文案裁剪至214,876字节；当前源代码中文字符检查无缺字。
- 运单式任务卡、薄荷安全区、快递橙强调、实时状态与投递进度条。
- 引入Kenney Factory Kit：设备、机械臂、输送带、管道、箱体；保留外部GLB贴图和原始许可证。
- 项目原创巡检机器人、货柜、平台、包裹、图标；不是下载一个现成完整游戏。
- 管理员悬浮、转向、巡逻与地面扇形；货柜切断视野。
- 成功粒子、失败红色提示、轻碰撞镜头反馈；设置可弱化闪光与镜头反馈。

### 音效
- Kenney按钮、投递成功、失败、木质/金属碰撞音。
- 碰撞声基于速度变化近似，设最低强度和冷却，随机轻微变调，使用6路播放器池。
- 靠近管理员时合成短提示音；音量、静音设置可保存。
- 静止地面接触不重复播放碰撞音，已做检查。
- 代码及真实浏览器碰撞事件已验证；最终音量平衡和听感仍应由用户实际试听。
- 未添加背景音乐；下载的脚步音为备用，悬浮管理员当前不播放脚步。

### 管理员
- 巡逻并在端点停顿、转向。不是锁死在一个位置的扇形。
- 视距约2.3–3.25世界单位，视角54–77度，随关卡增长。
- 用物理射线检测遮挡，货柜与墙体遮挡，地面标线与装饰不误挡。
- 检查包裹中心与四个侧面采样点，任一可见即发现。
- 开局1.2秒起步保护在状态栏明确显示；保护结束后被无遮挡看到即失败，无隐性累积条。
- 同帧发现与送达，失败优先。
- 暂停冻结巡逻、计时和物理；失焦自动暂停。

### 连续关卡
- 第1关后已有下一关入口；每次下一关按关号生成确定性布局。
- R重试保持当前关号和布局，不随机换一张图。
- 没有固定“最后一关”；不等于每张布局永不重复，也不等于存在无穷大有限存储。
- 6关起2名管理员，12关起3名；前约24关递增视距、视角、速度和障碍数，之后封顶并继续换布局。
- 最多3名管理员，最多17处货柜，不通过无限加速制造不可玩难度。
- 外围保留安全路线；中部穿行更短但会受视野威胁。这是当前生成策略的有意取舍：稳妥过关有保底，不声称外围绕行与冒险捷径有相同难度。
- 本地保存已解锁关号、音量、静音和弱化效果。尚未实现排行榜、逐关最佳成绩或多人模式。

运行 `tests/run_tests.gd`，实际转至当前版本 `tests/v2_tests.gd`：**32项，0失败**；最终运行无stderr错误。

包括：
- 6种实际使用GLB导入成功、关键中文字符字形存在。
- 前500关空间通路与巡逻安全间距检查。
- 同关种子一致、下一关改变布局、高关号参数封顶。
- 视角前方/背后/超距/角度外判定，真实墙体遮挡及移除后可见。
- 起步保护、保护结束后的立即失败、失败优先于投递。
- 投递边缘、高速、停留时长与成功判定。
- 下一关、同关重试、20次重开只保留一个包裹。
- 暂停冻结巡逻与时间、失焦暂停。
- 静止接触不触发碰撞音事件。

### 原生物理路线
`tests/physics_route.gd` 转至 `tests/v2_route.gd`，第1、24、100关均成功。
每关实际物理时间约15.03秒。控制器只通过Input action施力，不传送包裹、不关闭管理员、不强制胜利。
这些路线采用外围保底通路，不代表三个关卡的内侧捷径难度相同。

### 浏览器实测
- 浏览器版本154.0.8037.58，Windows本机；WebGL2、Compatibility、单线程。

- 按继续进入第二关；暂停后0.6秒计时与管理员位置保持不变；重试仍为第二关。
- 刷新后恢复第二关，验证本地关卡记录。

- 本机测试片段渲染帧率大致90–120 FPS；同时开原生窗口时有所下降。不是跨设备、移动端或长期运行性能承诺。
- 未测试Safari、Firefox、手机、低端GPU；当前正式目标仍是桌面键鼠。

### 测试工具限制
一次超过30秒的单次Playwright MCP调用被工具中止，结果未知，浏览器会话重启。未将该次调用计为成功。
重新连接后改为9秒一段的输入测试，并据游戏只读状态确认最终成功与失败结果。
`?qa=1`仅开启只读诊断（关号、位置、状态、帧率），没有远程执行、传送或强制通关接口。

## 已知边界

- 这是风格化低模的第二轮实机升级，不宣称已达到所有人审美中的“视觉极致”。
- 管理员为机器人，不是带完整人物骨骼动画的人类角色。
- 视野扇形按33条射线裁剪，边缘存在离散近似；真实判定以包裹采样点射线为准。
- 难度并非每关严格单调；后期封顶，外围始终有保底路线。
- 存档采用本机user://；隐私模式、清缓存或换浏览器可能丢失，不是云存档。
- 中文字体已裁剪，未来新增文案须重新检查字形覆盖。
- 工作目录不是Git仓库，Git检查不可用；已保留升级前源码备份并检查实际文件。
