# 0.4 巡检追捕 · 验收记录

## 玩法变化
- 地图从 11×9 扩大到 17×13（99 → 221 格，约 2.23 倍）。所有可走格连通，但不再保证外围永远安全。
- 五状态巡检：巡逻 → 调查 → 追捕 → 搜索 → 返回；多点路线与 BFS 绕障，看到约 0.65 秒确认目标，接近 0.72 米且无障碍才捕获。
- 巡检丢失视线后只追最后位置；搜索约 6 秒后返回。确认目标时可呼叫一台非追捕同伴，冷却 10 秒。
- 快速滚动、猛烈碰撞、诱饵发出不同范围的声音。声源只提供发声位置，货柜挡视线但不会完全隔音。
- Shift 轻运：限速 2、阻尼 1.15；默认移动保持限速 4、阻尼 0.75、重力 12、倾角 22 度、响应 0.16 秒。
- E / 右键：鼠标瞄准声响诱饵，落点不超过 5 米，吸引半径 7 米；每关 2 枚、到站补充 1 枚、最高 2 枚。直接看到玩家的追捕者不会立即被诱饵骗走。
- 每关先扫描通行标记；跨区任务再去东区中转站。到站需低速停留约 0.7 秒；追捕中不能办理或签收。
- 近距离跟随镜头、Tab 全图、离屏目标指引、机器人意图标签、确认进度、追捕提示。
- 准备界面“练习首关”保留原最高进度；背景音乐和原有碰撞音效继续使用。

## 限制与后续优先级
- 这是可解释的状态机与寻路，不是机器学习或真人智能。支援前往报告位置，尚无战术包围 / 预测截击。
- 关卡难度封顶、任务类型仍按轮换，不声称所有关卡独一无二或全部经过人工试玩。
- 未做全浏览器、移动端、长时间性能与人耳听感验收；测试期间并行运行和首次加载会影响帧率。
- 下一轮建议先做“可以改变路线的门禁 / 传送带”和“可选高风险额外委托”，再考虑技能成长；这些尚未实现。
