# 0.6.3 道具模型与任务音效

## 范围与保持不变的规则
本轮按确认的全部范围实施：四件背包装备、READY选中展示、场景任务/收集模型，以及分事件音效。继续使用Godot Compatibility；不引入商店、货币、装备重复、免费第三件道具或新的任务门槛。保留存档、插件、0.6.2指引/烟雾飞行/设备离线反馈。备份：`exports/backups/0.6.2-before-items`。

## 模型
`scenes/items/*.scn` 为11个可独立打开编辑的压缩PackedScene，由 `scripts/item_models.gd` 和 `tools/bake_items.gd` 重建。零外部模型依赖，材质/命名部件封装在场景内。

|用途|识别结构|
|---|---|
|烟雾罐|压力罐、色带、安全压杆、拉环|
|干扰器|防撞手持机、双天线、信号屏、按键|
|撬锁工具|展开工具盒、三根不同端头工具、搭扣|
|声音诱饵|扬声器网罩、顶部按钮、短天线|
|门禁卡|卡座、圆角卡片、金属芯片、条带|
|档案|叠层纸档、封皮、数据晶体、固定夹|
|备用电池|发光电芯、保护柱、电极|
|能源核心|更大的电芯、框架、搬运提手|
|下载终端|底座、立柱、屏幕、键盘|
|监控控制器|配电箱、指示灯、隔离拉杆、通风口|
|手动解封台|机械立柱、手轮、转柄|

场景物件由level_builder统一实例化；删除tactical_art的重复占位装饰。投出的烟雾罐和诱饵复用同一模型并缩小，不改变飞行/听觉/碰撞规则。

## READY选中展示
右侧单一独立3D视口展示当前编辑槽位的装备；中文名称、格子编号、用途提示、发光底座。装备卡与背包槽位采用金色双线、角标和短暂选中增亮；已装备但非当前编辑的卡保留绿色勾选，避免混淆“已装备”和“正在编辑”。模型短缩放过渡、慢速旋转；减少动态效果关闭旋转/选中缩放（切换时读取设置）。开始游戏隐藏并关闭视口更新，避免四个常驻3D窗口。

## 分事件音效
`tools/make_task_audio.py` 离线确定性合成原始WAV，不含采样来源不明的录音。`assets/audio/tasks` 共17条不同事件提示与1条下载循环。主要时长：

|事件|秒|特征|
|---|---:|---|
|门禁卡|0.72|短促上行电子提示|
|电池|1.00|低频充能上行|
|档案|1.75|四段数据归档音|
|启动下载|1.15|递进启动提示|
|下载中|1.00循环|低音量脉动，仅下载计时未满时|
|下载就绪|2.65|更长的上行完成尾音，仅触发一次|
|取回数据|1.10|独立回收提示，不重复播放就绪音|
|关闭监控|1.30|下行断电提示|
|手动解封|1.65|分段解锁|
|搬起/放下核心|1.45 / 0.50|低频取放区分|
|交付核心|2.90|较长充能完成段|
|开门/撬锁/破门|0.65 / 0.82 / 1.65|不同节奏|
|逃离成功|3.50|最长完成提示|
|暂时脱离追捕/被抓|1.70 / 1.25|舒缓下行/低沉失败|

战术收集不再全部使用880Hz通用提示。脚步、短装备声沿用现有通道；任务声音独立播放，不被脚步轮换覆盖。最多排队3条并去重，重要事件可替换低优先级排队项；成功/失败清理旧提示。暂停冻结任务/循环播放，静音清理旧队列，恢复声音仅重启仍在下载的循环；重试/换关彻底停止。音量跟随设置，下载循环明显低于任务提示。音效只负责反馈，不改变守卫听觉逻辑。

## 重建
先运行`python tools/make_task_audio.py`生成WAV，Godot导入后运行：
```
Godot --headless --path . --script res://tools/bake_items.gd
Godot --headless --path . --fixed-fps 60 --quit-after 1800 --script res://tests/run_tests.gd
```
必须同时检查显式RESULT和SCRIPT ERROR，不能只看进程退出码。新增中文已用`tools/subset_item_font.py`重建Item Sans SC子集并保留OFL，清单记录SHA256。
