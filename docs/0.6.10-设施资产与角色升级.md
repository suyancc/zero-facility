# 0.6.10 设施资产与角色升级

## 范围与参考

本轮综合查看项目根目录的六张参考图：潜行逃生设计图、机器人资产设定集、模块化资产图鉴、潜行资产设定集、道具概念图鉴、维护员概念设定集。不是只做一个房间的样板，而是把约定的角色、巡逻敌人、四区建筑陈设、11 类道具、准备界面与游玩画面一起更新。

参考图仅作为造型、色彩与功能分区的参考，没有裁切为贴图，也没有作为本项目原创宣传图上传。此版仍是原创、风格化的低多边形网页游戏；并非逐像素复刻参考图的写实渲染。枪械、攻击系统、无人机 AI、科研人员 NPC、可攀爬楼梯／翻越不在这轮已确认的玩法范围中，没有擅自加入。

## 角色

- 维修员的上身、袖子、裤腿改用连续椭圆截面网格，具有收腰、肩部过渡和轻微衣褶，而不是简单叠放圆角方块。
- 新增原创细织纹理，区分粗糙布料、橡胶、硬质护具与金属；深色裤装、灰白上衣和橙色挂带保持一致。
- 缩小头身比，重做下颌、头发轮廓、耳鼻、眼睛与眉部；保留背包、工具、胸前终端、手套和靴子。
- 保留原命名关节与独立手脚；步行／跑步之外，潜行增加髋膝弯曲，持续交互增加手部操作姿态。搬运和结算动作继续保留。
- 脚底仍用关节角度计算贴地补偿。只改表现，不改人物碰撞体、速度、体力或交互判定。
- 准备界面展示实际烘焙场景，采用静态站姿；进入游戏后禁用该预览的渲染。

## 巡逻机器人与摄像头

- 主巡逻机器人改为无武器双足关节结构：白灰外壳、黑色关节、金属活塞、橙色标识和圆形光学传感器。
- 用真实移动距离推进步态；站立不继续推进走路相位，膝盖和足部做贴地补偿。各刚性部件独立合批，不把活动关节焊死。
- 正常状态为冷蓝传感器，调查／搜索为暖色，确认／追捕为红色；保留已有警报音、视野遮挡和追捕状态机。
- 摄像头增加支架、遮光罩、圆形镜头与外壳细节，继续沿用原扫描与确认逻辑。
- 未更改视野射线高度、确认时长、导航阻挡、追捕速度或捕获距离。

## 四区与建筑

| 区域 | 主要识别结构 |
|---|---|
| 监控室 | 多屏监控墙、操作台、监控型柜体 |
| 数据机房 | 连排服务器、散热格栅、状态灯与顶部服务结构 |
| 仓储区 | 多层货架、不同尺寸加固箱、锁扣与标签 |
| 能源舱 | 红色反应装置、支撑笼、辅助设备与连接管 |

- 四区均有独立的背景设备组合，并更新可玩区域中现有掩体的外观。没有把一台机器重复改色当作四个区域。
- 大型背景装置位于可玩碰撞边界之外，不占任务格、不挡出口。可玩掩体保留原碰撞体和高度，机器外观尽量落在其占地内。
- 旧的包裹传送带与外围纸箱工厂背景被固定服务设备、检修步道、护栏和楼梯替换。
- 门增加门框、横梁、面板与状态条；保留原维修门开启与碰撞逻辑。
- 保留已有墙板、地板分缝、管线与编号；降低连续青色墙顶的霓虹感，改用更克制的材料色。
- 不新增实时灯，调整四盏既有区域灯的冷暖色：监控冷白、机房冷蓝、仓储暖黄、能源暖红。原阴影和 MSAA 不降低。
- 总览时隐藏地面区域字，只保留总览房间标签，避免两套名称重叠。

## 道具与界面

全部 11 类继续使用真实 3D 场景，保留 `item_kind` 与可编辑的语义零件节点：

1. 烟雾罐：罐体压边、保险环、压杆、标识带。
2. 干扰器：双天线、波形屏、加固角和提手。
3. 开锁工具：折叠工具盒、三件工具、握柄与锁扣。
4. 声音诱饵：球形机壳、扬声器网罩、按钮和天线。
5. 门禁卡：芯片、识别条和细节编码。
6. 档案资料：叠层资料盒与数据模块。
7. 备用电池：发光电芯、端盖、固定件与标牌。
8. 能源核心：提手、支架、端部固定件与核心电芯。
9. 数据终端：屏幕、键盘、加固角和立柱散热口。
10. 监控控制器：双屏状态显示、侧面隔离手柄。
11. 手动解锁装置：机械轮、手柄、警示面板与底座。

四张准备装备卡和两格背包的 PNG 缩略图重新从当前 Godot 模型渲染，保持透明背景，并继续保留右侧可旋转的大模型预览。缩略图工具改为独立临时服务器和 QA 提供的实际控件坐标，不依赖旧 UI 的硬编码点击位置。

普通游玩隐藏空闲单位名称；高风险／追捕时优先显示危险提示，暂时隐藏普通物品浮字，避免互相遮挡。按 Tab 总览仍可查看全部任务物品名称，HUD 与目标指引保持可用。

品牌区增加原创矢量标记；准备、HUD、设置、暂停和结果沿用统一工业终端主题。现有实际任务简报、两件不同装备、数量、快捷键、冷却、设置保存和减少动态效果选项不变。

## 性能与验证方法

- 静态装置和各道具子组件按材质合并；机器人的活动肢体分别合并，确保关节仍可驱动。
- 连续截面网格增加 Godot 顺时针正面绕序检查，防止原生逻辑测试通过但网页看见反面／缺面。
- 完整原生检查实测 243 项、0 失败，原有 49 项回归同样 0 失败。
- 9 个任务配置使用原路线夹具验证：冻结危险单位、清空消耗品，隔离任务／门／出口连通性。这不是九关真人潜行成功率测试。
- 网页检查覆盖三种桌面尺寸、真实点击选装、设置开关、开始、暂停、重试，以及调整窗口后人物预览仍可见。
- 性能对照使用实际已发布的 0.6.9 Web 文件，并校验基线文件哈希。短时静止场景的帧间隔不能替代追捕、高 DPI、低端设备和长时间游玩的测试。
- 保留并重跑 WebAudio 的默认声音、静音、发现提示、暂停衰减与重复启动检查；不修改混音逻辑，不宣称所有设备上的物理噪声均已消除。

## 工程文件

- `scripts/surface_geometry.gd`：连续截面网格与椭球工具。
- `scripts/patrol_body.gd`：独立刚性关节的巡逻机器人与行走表现。
- `scripts/facility_assets.gd`：箱体、屏幕、机柜、反应设备及四区组合。
- `assets/materials/workwear-weave.png`：原创织纹；可用 `tools/make_workwear_texture.py` 重建。
- `scripts/escape_player.gd`、`scripts/item_models.gd`：人物与全部道具构建器。
- `tools/bake_character.gd`、`tools/bake_items.gd`、`tools/bake_item_thumbnails.py`：实际场景及缩略图生成。
- `tests/v610_assets_tests.gd`、`tests/web_visual_v610.py`：新增验证。

原项目的 Godot MCP 配置继续保留。公开仓库和 Web 导出仍走隔离、去私有配置的发布工程。用户原有 8765 页签不由自动化关闭或刷新。
