# 零号设施 0.6：关内多方案

2026-10-04。实施范围为已确认的第一轮：两格装备、烟雾/干扰/撬锁、房间/维修门/摄像头、三类任务。不包括营救AI、门楔、侦察探头、剧情战役或随机事件。

## 一、任务循环

区域1、4、7…为突破封锁；2、5、8…为盗取数据；3、6、9…为能源转移。区域编号改变布局、物品位置、出生点、出口与巡逻参数；重试确定性复现。

|任务|基础方案（不依赖消耗品）|可选方案|实际完成条件|
|---|---|---|---|
|突破封锁|寻找门禁卡；或在手动解封台长按4秒|装备撬锁，出口长按3秒直接破门|门打开后实际走出|
|盗取数据|启动终端，利用巡逻间隙或控制器避开监控|烟雾遮挡、EMP制造操作窗口|下载10秒，返回长按取回，再开门走出|
|能源转移|沿公共通道搬运，必要时放下探路|卡/撬锁/控制器打开维修捷径，烟雾掩护|核心带到出口长按交付，再开门走出|

下载不是长按10秒：启动后可离开，计时完成也不会自动把数据送到玩家背包。核心不是一次拾取：搬运限制速度与奔跑，可在实际位置放下、重新搬起。不会自动传送到出口。

## 二、两格装备

出发前下拉选择两个不同装备，开局锁定，重试恢复本次选择及数量。不额外免费携带第三种诱饵。按1/2直接使用对应装备，撬锁先准备，再靠近门长按E；再次按装备键可收起。鼠标地面标记显示当前选中装备作用范围。

|装备|数量|参数|边界|
|---|---:|---|---|
|烟雾罐|2|投掷不超过5米，半径2.2米，持续6秒|阻挡视线线段并截短地面视锥，不消除声音、记忆或近身抓捕；不能隔实体墙投掷|
|干扰器|1|玩家周围3米；巡检暂停4秒，监控离线7秒|没有有效设备不消耗；不清除追捕状态、已记录警报或过去目击点|
|撬锁工具|2|维修门2.2秒；解封任务出口3秒|取消交互不消耗；操作发声；不能跳过下载/核心任务|
|声音诱饵|2|保留原有延迟发声与声音调查|只有装备后才可用Q/右键或装备槽按键，数量共用|

通用装备冷却0.6秒。暂停冻结设备、烟雾及下载计时。搬运速度1.8米/秒，搬运潜行1.2米/秒，无法冲刺；F放下。

## 三、空间与功能设备

- 四个着色分区：监控室、数据机房、仓储区、能源舱。分区有实体隔墙，不再只是不同颜色的箱子。
- 公共通道始终可通行；维修门提供穿越隔墙的短路线。地图验证在维修门关闭时进行，不将消耗品作为主任务可达条件。
- 每张地图的维修门在两侧相邻点之间提供可量化缩短：关闭时绕行，打开后3个网格节点直接穿过。
- 刷卡、撬锁、局部控制器都可永久打开维修门；同时更新实际碰撞和巡检共享寻路数据，巡检也可能使用新捷径。
- 局部控制器是功能性支线：监控离线45秒，同时开启维修门。档案仍保留为额外评价目标，不强制收集。
- 两台扫描摄像头，视角62度、范围4.5米、约0.9秒确认。确认后报告位置让巡检调查，不直接判失败，重复报告有8秒冷却。
- 保留高低掩体、确认→追捕→搜索、体力、脚步、警戒红色闪烁及减少闪烁设置。

目前是四分区原型，不宣称每个房间都有复杂专属系统。任务物品仍会分散生成，不强制“数据只能出现在名为数据机房的房间”。下一轮可进一步做语义化房间模板。

## 四、架构与存档

- tactical_generator.gd：调用基础生成器，构造隔墙/通道/锁门、重新放置任务点、修正巡逻路点。
- tactical_controller.gd：继承基础关卡控制，处理装备、烟雾、下载、搬运、维修门与新任务条件。
- tactical_camera.gd：复用视锥/遮挡绘制，独立扫描、确认、报告与干扰恢复。
- tactical_art.gd：原创分区、功能门、终端和摄像头几何体。
- game_flow.gd 默认 tactical_mode=true；旧机制只供回归测试，不在玩家设置中暴露。
- 新成绩保存在同一存档的 tactical 小节，旧 escape 成绩保留但不拿来与新任务比较；最高解锁区域、音量等延续。保存时加载原文件再更新，不删除旧小节。
- test_mode 不保存。没有重置用户最高区域。

## 五、后续建议

优先人工试玩并调整任务阅读成本、移动路线与警戒压力；再扩展营救/破坏两类任务。门楔需要完整的关门与堵门状态机，侦察探头需要信息界面，不在本轮用外观假装实现。暂不增加货币、商店、技能树。
