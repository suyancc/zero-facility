# 0.6.2 目标指引与道具反馈

日期：2026-10-04。继承0.6.1的两格背包与柔边烟雾；不重置最高区域、音量或既有成绩。本轮不是新增任务类型。

## 1. 可切换的目标指引
- 按T或点背包下方的目标按钮，循环切换当前可用方案和支线；按钮显示名称及直线距离。
- 突破封锁可跟踪门禁卡、手动解封台、撬锁直达出口。未携带/耗尽撬锁时，不把撬锁方案列为可用选择。
- 主动准备撬锁时，默认卡片指引会切换到出口；若玩家已手动跟踪别的支线，不强行覆盖。
- 下载完成后指令变为“取回下载数据”；核心搬起后指向交付点，放下后指回实际放置位置。
- 可跟踪局部控制器、可开启的维修门、最近未收集档案。完成或失效的目标回到当前主目标。
- 场内细线标记、场外方向箭头、文字指引同步更新。近边缘但仍可见的目标不再重复堆叠方向文字。
- 跟踪仅提供方向，不自动寻路、不替玩家开门，也不改变通关条件。

## 2. 烟雾弹飞行与落地
- 同一轨迹函数用于预览和实际弹体移动，飞行0.55秒；金属罐有可见飞行及旋转过程。
- 预览由25个点组成的细虚线弧线及落地区域构成，受阻变淡红；释放前再验证，受阻不扣数量。
- 用分段射线及小型周边偏移检测罐体通行空间，低掩体与高墙按实际弧线检测。并非完整刚体反弹模拟。
- 道具在释放时扣除，飞行中不遮挡视线；落地后才开始完整6秒烟雾。
- 投出声与落地起雾声分离。暂停冻结飞行、烟雾和作用时间。
- 若飞行途中发生新的阻挡，在最后可落地的安全位置起雾，不穿过碰撞体继续飞行。
- 这会增加提前量要求，不能再把烟雾当作立即生效的保命按钮。

## 3. 干扰命中反馈
- 提示真实命中数量，只对范围内实际受影响的设备添加效果。
- 设备附带蓝色离线图标、剩余时间条及倒计时；命中瞬间出现短促电路线，随后自行淡出。
- 眼灯变暗，主动视锥停止，恢复后移除离线标记。巡检4秒、监控7秒的效果时间保持不变。
- 局部控制器关闭监控45秒时也使用对应离线提示。
- 减少动态模式隐藏电路线运动，但保留图标、进度条和文字信息。
- 没有设备命中时不耗次数，不制造“成功释放”的假反馈；已存在的追捕记忆与警报不被清除。
- 常规行动中收起重复的“你”大字，只在准备、起步保护和俯瞰时显示，减少与设备状态文字重叠。
